# Spec: Hero Card Button & Copy Refinement

## Goal
Improve the visibility of the "Login" button on the Hero card and update the call-to-action (CTA) copy to align with a founder-focused waitlist strategy.

## Requirements
- Target: `HeroContent` buttons in `landing_screen.dart`.
- **Button Style**: Change the `OutlinedButton` (Login) border color to pure white.
- **Copy Changes**:
    - "Login" -> "Become a Founder"
    - "Get Started" -> "Join Waitlist"

## Success Criteria
- [ ] The outlined button has a white border instead of light green.
- [ ] The button text is updated to "Become a Founder".
- [ ] The primary button text is updated to "Join Waitlist".
