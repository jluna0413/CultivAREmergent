# Spec: Electric Gradient Enhancement

## Goal
Enhance the visual appeal of the landing page feature cards by replacing the semi-transparent surface color with a vibrant electric green to violet (purple) gradient.

## Requirements
- Target: `FeatureSection` and `NutrientFeatureSection` cards.
- Colors: Electric Green (e.g., #00FF00 or project primary) and Violet/Purple (e.g., #8A2BE2).
- Style: Maintain glassmorphism (backdrop blur) and subtle borders.
- Responsiveness: Ensure gradient looks good on both mobile and desktop views.

## Success Criteria
- [ ] Feature cards display the specified gradient background.
- [ ] Text remains readable over the new gradient.
- [ ] Backdrop blur is preserved.
