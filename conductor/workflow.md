# Workflow: CultivAR

## Development Process
- **TDD Preferred**: Write tests before implementing features when possible.
- **Commit Strategy**: Meaningful commit messages, feature branches.
- **Verification**: All UI changes must be verified via browser screenshots/videos in Antigravity.
- **Agentic Flow**: Use Conductor Tracks for all major features and bug fixes.

## PR Strategy
- Detailed descriptions with screenshots.
- Mandatory peer review (even for agents).
