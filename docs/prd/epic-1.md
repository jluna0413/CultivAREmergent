# Epic 1: Core Plant & Cultivation Management

## Description

This epic covers the foundational features for creating, tracking, and managing plants throughout their entire lifecycle. It includes core CRUD operations for plants, detailed activity logging, and the introduction of cloning to preserve superior genetics. This epic establishes the base functionality upon which more advanced features like environmental automation and detailed analytics will be built.

## Stories

-   **1.1: Basic Plant Creation**
    -   **As a user,** I want to create a new plant entry with essential details like name, strain, and start date, so that I can begin tracking a new grow.
-   **1.2: Plant Status Tracking**
    -   **As a user,** I want to update the growth stage of my plant (e.g., Germination, Seedling, Vegetative, Flowering, Harvested), so that I can accurately monitor its progress through the lifecycle.
-   **1.3: Plant Detail View**
    -   **As a user,** I want to view all the recorded details of a specific plant in one place, so that I can get a comprehensive overview of its history and current status.
-   **1.4: Plant List View**
    -   **As a user,** I want to see a list of all my current and past plants, so that I can easily navigate and manage my entire collection.
-   **1.5: Plant Activity Logging**
    -   **As a user,** I want to log various activities against a plant, such as watering, feeding, and general notes, so that I can maintain a detailed history of my actions.
-   **1.6: Plant Cloning Management System**
    -   **As a user,** I want to create and track clones from a parent plant, so that I can preserve superior genetics and scale my grow operation with consistent quality.
-   **1.7: Plant Image Gallery**
    -   **As a user,** I want to upload and view multiple images for each plant, so that I can visually track its growth and health over time.
-   **1.8: Plant Archiving & Deletion**
    -   **As a user,** I want to archive completed grows or delete incorrect plant entries, so that I can keep my active dashboard clean and organized.
-   **1.9: Basic Environmental Data Logging**
    -   **As a user,** I want to manually log basic environmental data points like temperature and humidity for a plant's grow space, so that I can start correlating environmental conditions with plant health.
