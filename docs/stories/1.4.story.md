# Story 1.4: Wire AI Dashboard Provider to UI Screen with Loading/Error States

## Status: Draft

## Story

As an AI dashboard user,
I want to see real AI activity data with proper loading and error states,
So that I can track my AI usage and get meaningful insights from the dashboard.

## Acceptance Criteria

### Functional Requirements

1. AI dashboard provider fetches real AI dashboard data using AsyncValue pattern
2. Provider displays loading states during data fetching with skeleton/spinner UI
3. Provider handles API errors gracefully with user-friendly error messages
4. Recent AI activity section shows actual activity data instead of empty state
5. AI dashboard stats cards display live data from backend API

### Integration Requirements

6. AI dashboard provider connects to ai_dashboard_api_client service
7. API client uses existing Dio HTTP client with proper authentication
8. Provider follows existing AsyncValue pattern from dashboard_provider.dart
9. No breaking changes to existing AI dashboard UI layout and styling

### Quality Requirements

10. Provider follows Riverpod AsyncValue pattern consistently
11. Error handling includes network failures, authentication issues, and server errors
12. Provider is testable with mocked API service
13. Code follows existing Flutter project patterns and conventions

- Auth: JWT Bearer token (handled by Dio interceptors)
- Response: {"stats": {...}, "recent_activities": [...]}

- Provider Type: Riverpod FutureProvider with AsyncValue<AIDashboardStats>
